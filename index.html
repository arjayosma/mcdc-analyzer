MC/DC Analyzer: MC/DC coverage for JavaScript and TypeScript

Find the smallest set of tests that proves every condition in your code actually changes the outcome (modified condition/decision coverage). For every if, loop, ternary and && / || expression, MC/DC Analyzer works out the tests you need, traces each one through your code, and measures which ones your tests already cover.

  • Minimal MC/DC test sets with short-circuit-aware truth tables (masking or unique-cause).
  • Control-flow and condition-flow graphs with the selected test's path highlighted.
  • Measured coverage: run your calls in the browser and see which tests are still needed.
  • Analyze a whole project folder, with .gitignore support.
  • Export a standalone HTML report and an AI prompt for the missing tests.

Free and open source (MIT). Your code is analyzed in your browser and never uploaded. Source code on GitHub.
